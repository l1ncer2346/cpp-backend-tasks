# Игровой сервер «Пёс-собиратель»

Финальная версия сервера: генерация и сбор трофеев, начисление очков, сохранение состояния,
уход игроков на покой и таблица рекордов в PostgreSQL.

## Сборка и запуск в Docker

```sh
docker build -t game_server .
docker run --rm -p 8080:8080 -e GAME_DB_URL=postgres://user:password@host:5432/db game_server
```

## Параметры командной строки

* `-c, --config-file <file>` — путь к конфигурации игры (обязательный);
* `-w, --www-root <dir>` — каталог статических файлов;
* `-t, --tick-period <ms>` — период автоматического обновления игры; без него время продвигается через `POST /api/v1/game/tick`;
* `--randomize-spawn-points` — появление псов в случайных точках дорог;
* `--state-file <file>` — файл для сохранения и восстановления состояния игры;
* `--save-state-period <ms>` — период автоматического сохранения состояния (в игровом времени).

Адрес базы данных задаётся переменной окружения `GAME_DB_URL`.

## Уход на покой

Если пёс стоит на месте дольше `dogRetirementTime` секунд (параметр конфигурации, по умолчанию 60),
игрок покидает игру, а его имя, очки и время игры сохраняются в таблицу `retired_players`.

Рекорды: `GET /api/v1/game/records?start=0&maxItems=100` (`maxItems` не больше 100).
Сортировка — по убыванию очков, затем по времени игры и имени.
